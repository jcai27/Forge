# Design Partner Pilot

## Offer

- 60-day pilot
- fixed backend API track
- fixed report format
- human-reviewed credential
- weekly pilot review with hiring manager

## Success metrics

- Review time under 10 minutes
- At least one live hiring decision from the report
- Candidate completion rate high enough to keep the flow usable
- Positive feedback on trust and portability

## Weekly review agenda

1. Candidate volume and completion
2. Submission quality and failure reasons
3. Employer decision outcomes
4. Report usefulness and missing evidence
5. Changes requested for the next pilot sprint
