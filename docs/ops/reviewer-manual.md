# Reviewer Manual

## Goal

Produce a reusable, comparable credential that an employer can trust without reading a raw repository for 45 minutes.

## Review workflow

1. Read the report summary before opening the timeline.
2. Check correctness, benchmark band, and integrity summary.
3. Score the rubric dimensions.
4. Open the timeline only to resolve uncertainty or validate ownership.
5. Record one decision: `advance`, `interview`, `reject`, or `offer`.

## Escalation rules

- Escalate all flagged submissions for second review.
- Escalate if timeline evidence conflicts with the code quality level.
- Escalate if AI usage appears inconsistent with the candidate explanation.

## SLA

- Automated report: within minutes of submission.
- Human-reviewed report: within one business day.
