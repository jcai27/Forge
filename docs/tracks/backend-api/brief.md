# Backend API Track Brief

## Scenario

You are joining a small logistics company that needs a reliable inventory adjustments API for warehouse operators and downstream reporting systems.

## Candidate task

Implement and improve a backend service that can:

- Create inventory adjustment events.
- Prevent invalid or duplicate adjustments.
- Expose filtered query endpoints for warehouse and SKU history.
- Keep tests green and extend test coverage where the starter repo is weak.
- Document one design tradeoff you made under time pressure.

## What is being assessed

- Correctness and stability.
- API design judgment.
- Data validation and error handling.
- Incremental debugging and testing behavior.
- How clearly the candidate explains tradeoffs.

## Guardrails

- Use the hosted environment only.
- AI assistance is allowed.
- The final report will include tests, timeline, AI usage summary, and reviewer rubric.
